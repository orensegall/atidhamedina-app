# atidhamedina-app

This repository contains a small command line application that offers supportive messages based on simple psychology research. The goal is to help users relieve feelings that may arise from social damage.

## Disclaimer
The application is not a substitute for professional mental health advice. If you are experiencing severe emotional distress, please consult a qualified professional.

## Usage
Run the app with Python 3:

```bash
python3 app.py
```

Then type how you are feeling to receive a supportive suggestion. Type `quit` to exit.
